The \aschip \; Variant~A (RTL top \texttt{RV\_NoPipeline}, core \texttt{as\_cpux};
see Table~\ref{tab:asChipVariants}) is a students test chip. It implements no MMU.

The core is a non-pipelined, multi-cycle implementation without cache.
A finite state machine runs each instruction through the states
\texttt{FETCH0\_ST} $\rightarrow$ \texttt{FETCH1\_ST} $\rightarrow$ \texttt{EXEC\_ST}
(three core clock cycles). Loads take one additional state \texttt{EXECLD\_ST}
(four cycles). \texttt{wfi} stays in \texttt{EXEC\_ST} until an interrupt is
pending (Section~\ref{subsec:irqconcept}).
Instructions and data are held in on-chip SRAM only (no memory hierarchy), so
there are no pipeline hazards.
