The system memory consists of two on-chip SRAMs (Harvard architecture,
see Section~\ref{subsec:chipVariants}):
\begin{itemize}
  \item The Instruction Memory (32\,kB) is loaded at start-up via the JTAG scan
    chain and is read-only during normal execution.
  \item The Data Memory (8\,kB) is fully read/write and serves as the sole
    writable data store (stack, heap, \texttt{.data}, \texttt{.bss}).
\end{itemize}
There is no cache, no external memory and no QSPI controller.
