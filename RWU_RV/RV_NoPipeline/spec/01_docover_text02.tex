This document is valid for \aschip \; version:
\begin{itemize}
  \item V1.0: First samples
  \item V1.x: Revision
\end{itemize}

This document specifies \textbf{Variant~A} of the \aschip{} (RTL top
\texttt{RV\_NoPipeline}), the variant prepared for the first tapeout.
Variant~B (\texttt{RV\_PipelineCacheFwd}) is specified in a separate document.
Chapters that describe shared IP blocks (ALU, decoder, GPIO, UART, ICU,
interrupt and bus concept) are common to both documents.
