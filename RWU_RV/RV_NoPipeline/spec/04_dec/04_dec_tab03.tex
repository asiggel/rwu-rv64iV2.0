Table \ref{tab:asDec01} shows the input and outputs of the Instruction
Decoder (\texttt{as\_instr\_decode}), matching
\texttt{RWU\_RV/RV\_NoPipeline/src/asInstrDecode.sv}. This is a purely
combinational module: no \texttt{clk\_i}/\texttt{rst\_i}, no internal
state, all outputs are a function of the current inputs only. There is no
bi-directional, tristate or open drain pin.
