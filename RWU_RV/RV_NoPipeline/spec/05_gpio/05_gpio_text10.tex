\subsubsection{Interrupt Registers}
\label{subsec:gpioirqregs}
The interrupt registers are implemented by the shared block \texttt{as\_irq\_peripheral} (\texttt{ip\_irqper/src}), which is also used by UART0. GPIO0 instantiates it with irqs\_yes\_no\,=\,1, i.e.\ with the additional source registers IRQSS, IRQSM and IRQSC for the eight interrupts of the same type (one per pin). The kernel delivers a one-clock-cycle pulse per detected edge.

\paragraph{Clearing a GPIO interrupt.}
RIS[0] is not a separately stored bit but the level |(IRQSS \& IRQSM). An interrupt service routine therefore only has to write the pending pin bits to \asgpioIRQSCRegExt; RIS[0], MIS[0] and gpio\_irq\_o drop in the same cycle once no unmasked IRQSS bit is left. \asgpioICRRegExt is only needed for bits that were forced by software via \asgpioISRRegExt.

\paragraph{Coincidence of set and clear.}
If a pin edge (or an ISR write) and a clear write hit the same bit in the same clock cycle, the set wins, so no event is lost.

\paragraph{ICU0 interaction.}
ICU0 latches the rising edge of gpio\_irq\_o. If several pins are pending and the ISR clears only some of them, gpio\_irq\_o stays high and ICU0 sees no new edge. The ISR must therefore clear all pending bits it read from \asgpioIRQSSRegExt (or loop until \asgpioMISRegExt = 0) before it returns.
