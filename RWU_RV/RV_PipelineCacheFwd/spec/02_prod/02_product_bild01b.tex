
Figure \ref{fig:asTop01B} shows the top level of the chip (Variant B,
RTL: \texttt{RV\_PipelineCacheFwd}). Compared to Variant~A
(separate specification), the multi-cycle CPU and direct I-Mem/D-Mem
are replaced by the 5-stage pipelined CPU (\texttt{cc\_cpupipefwd}) and
the \texttt{asMemTop} memory subsystem (I-Cache, D-Cache, Scratchpad SRAM,
AXI4 Memory Arbiter) feeding a QSPI Flash controller. The Wishbone
peripheral set (CGU, GPIO, UART0, ICU0, JTAG) is unchanged from Variant A.
