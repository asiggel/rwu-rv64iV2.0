This document specifies \textbf{Variant~B} of the \aschip{} (RTL top
\texttt{RV\_PipelineCacheFwd}). Variant~A (\texttt{RV\_NoPipeline}, first
tapeout) is specified in a separate document.
Chapters that describe shared IP blocks (ALU, decoder, GPIO, UART, ICU,
interrupt concept, Wishbone bus) are common to both documents.
